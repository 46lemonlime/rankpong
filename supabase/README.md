# Supabase Directory

This folder contains local development and infrastructure definitions for Supabase:
- `migrations/` - PostgreSQL SQL migration scripts managed via Supabase CLI.
- `seed/` - Development seed data for local testing (`seed.sql`).
- `functions/` - Supabase Edge Functions (Deno runtime).

> Note: Per initial scaffolding restrictions, database schemas, tables, and migrations are deferred to the subsequent milestone.
