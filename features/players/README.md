# Players Feature (`features/players`)

## Scope
Player profiles, head-to-head records, play style, handedness, equipment details, and historical career stats.

## Planned Structure
- `components/` - PlayerCard, PlayerAvatar, HeadToHeadComparison, StatBadge
- `actions/` - updateProfileAction, uploadAvatarAction
- `schemas/` - profileSchema
- `types/` - PlayerProfile, HeadToHeadRecord
